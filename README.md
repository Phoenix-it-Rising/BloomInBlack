# BloominBlack

A full-stack social networking platform built with React Native, Expo, Express.js, and PostgreSQL.

## Features

- User profiles
- Social feed
- Post creation
- Image sharing
- Likes
- Comments
- Nested replies
- Mobile-first design

## Tech Stack

Frontend:
- React Native
- Expo
- TypeScript

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL
